# 📊 Análisis de Datos: TechNova

Proyecto de visualización de datos en Python para analizar la estructura organizacional, el histórico de contrataciones y la equidad salarial en la empresa **TechNova**.

## 📌 Preguntas del Negocio

1. **Distribución del personal:** ¿Qué departamentos concentran la mayor cantidad de empleados?
2. **Evolución histórica:** ¿Cómo impactó la congelación de contrataciones y cómo fue su posterior recuperación?
3. **Equidad salarial:** ¿Existe alguna relación o sesgo entre la edad de los colaboradores y su salario?

---

## 🛠️ Herramientas Utilizadas

- **Lenguaje:** Python 3
- **Librerías:** Pandas, Matplotlib, Seaborn
- **Entorno:** Google Colab / Jupyter Notebooks

---

## 💡 Principales Conclusiones

- **Departamentos:** El área de **Tecnología** representa el volumen principal de la plantilla, lo cual se alinea con el rubro de la empresa.
- **Tendencia de contrataciones:** Se observa una baja pronunciada en las contrataciones durante **2020**, con una recuperación constante a partir de **2022**.
- **Equidad salarial:** No existe correlación entre la edad y el sueldo ($r \approx 0$). Las remuneraciones se otorgan de manera equitativa sin sesgo etario.
